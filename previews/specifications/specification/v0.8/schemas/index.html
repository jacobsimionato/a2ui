v0.8 JSON Schemas

Legacy A2UI v0.8 defines wire envelopes, standard catalog structures, and client capability schemas across 7 JSON Schemas included from specification/v0_8/json/. For current integrations, see v0.9.1 JSON Schemas or v1.0 JSON Schemas.

Wire messages

server_to_client.json

A2UI Message Schema — Describes a JSON payload for an A2UI (Agent to UI) message, which is used to dynamically construct and update user interfaces. A message MUST contain exactly ONE of the action properties: 'beginRendering', 'surfaceUpdate', 'dataModelUpdate', or 'deleteSurface'.

Source: specification/v0_8/json/server_to_client.json ↗ · Raw JSON ↗ · Permalink
Definitions & properties (4)
Properties: beginRendering, surfaceUpdate, dataModelUpdate, deleteSurface

client_to_server.json

A2UI (Agent to UI) Client-to-Server Event Schema — Describes a JSON payload for a client-to-server event message.

Source: specification/v0_8/json/client_to_server.json ↗ · Raw JSON ↗ · Permalink
Definitions & properties (2)
